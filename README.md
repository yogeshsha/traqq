🛒 Traqq - E-commerce App
Welcome to Traqq, a sleek and modern e-commerce mobile application designed to offer a smooth and intuitive shopping experience. Whether you're browsing for products or managing your cart, Traqq ensures a fast, responsive, and visually appealing interface — with support for both dark mode and light mode.

✨ Features
🛍️ Product Listing
Browse a list of available products in a clean, user-friendly layout.

🛒 Add to Cart
Easily add or remove items from your cart with real-time updates.

💰 Cart Summary with Total Calculation
View your selected items along with a dynamically updated total cost.

🌓 Light & Dark Theme Support
Automatically adapts to your system theme or toggle manually.

🧠 Bloc Architecture
Robust and scalable state management using Flutter Bloc, making the code clean, testable, and maintainable.

💾 Persistent Cart with SQLite
Your cart data is stored locally using SQLite, ensuring data is preserved even when the app is closed or restarted.

🔐 Secure API Integration via Abstract Classes
API interactions are handled via well-structured abstract classes, enforcing a clear separation of concerns and enhancing security and flexibility.
